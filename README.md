# Solana Token Landing Page

A hacker-themed, terminal-style landing page for Solana tokens built with React, Vite, and Tailwind CSS.

## Features

- 🖥️ Terminal-style UI with hacker aesthetic
- ⚡ Boot sequence animation
- 📋 Contract address with copy functionality
- 📊 Token statistics display
- 🔗 Social media links integration
- 📱 Fully responsive design
- 🎨 Custom animations and effects

## Tech Stack

- **React** - UI framework
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Lucide React** - Icons

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
cd solana-templates
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm run dev
```

4. Open http://localhost:5173 in your browser

## Configuration

Edit the `CONFIG` object in `src/App.jsx` to customize:

- Token ticker symbol
- Contract address (CA)
- Total supply
- Telegram link
- Twitter/X link
- Pump.fun link

## Build for Production

```bash
npm run build
```

The built files will be in the `dist` directory.

This project is configured for easy deployment on Vercel. See `DEPLOYMENT.md` for detailed instructions.
